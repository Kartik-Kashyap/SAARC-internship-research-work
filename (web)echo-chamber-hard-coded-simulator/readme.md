# 🧠 Social Media Algo Simulator: Echo Chamber Lab

An interactive behavioral simulation designed for the **AI-Mediated Digital Citizenship Lab**. This tool demonstrates the psychological and cognitive impacts of engagement-based algorithms on youth within the SAARC region.

### 🔗 Live Simulation

**Experience the feedback loop here:** [Social Media Echo Chamber Simulator](https://social-media-echo-chamber-simulator.netlify.app/)

---

## 🧪 Project Purpose

This simulator acts as an educational "sandbox" to show how AI algorithms prioritize emotional engagement over factual depth. By tracking user clicks in real-time, the system builds a "filter bubble," illustrating how digital citizenship can be eroded by automated content curation.

### Interactive Research Elements:

* **Dynamic Feed Personalization:** The algorithm analyzes your "consumption" history to prioritize polarizing or shallow content.
* **Live Cognitive Metrics:** Tracks four key indicators:
* **Attention Span:** Decays with high-dopamine, short-form content.
* **Polarization Index:** Increases as the user engages with "us vs. them" narratives.
* **Critical Thinking:** Fluctuates based on the consumption of educational vs. unverified content.
* **Diversity Score:** Measures exposure to cross-border (SAARC) perspectives.

## 🛠️ Technical Architecture

* **Deployment:** Hosted on **Netlify** via a static build.

---

## 📖 How to Use the Simulator

1. **The Feed:** Users are presented with a mix of "Polarizing," "Educational," "Balanced," and "Dopamine-heavy" posts.
2. **The Interaction:** Clicking a post "consumes" it, triggering an algorithmic update.
3. **Interventions:** If the user displays high-risk behavior (e.g., clicking 3 polarizing posts in a row), the system triggers an **Educational Intervention**.
4. **The Report Card:** At the end of the simulation, users receive a **Digital Citizenship Grade** (A through D) based on their average cognitive metrics.
