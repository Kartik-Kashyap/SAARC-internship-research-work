# 🌏 SAARC AI Assistant

An intelligent chatbot focused on South Asian Association for Regional Cooperation (SAARC) member nations, promoting regional understanding and cooperation.

## ✨ Features

- 🤖 **AI-Powered**: Uses Llama 3.2 for intelligent, context-aware responses
- 🎯 **SAARC-Focused**: Only answers questions related to SAARC and South Asian affairs
- 🚩 **8 Member Nations**: Afghanistan, Bangladesh, Bhutan, India, Maldives, Nepal, Pakistan, Sri Lanka
- 🎨 **Beautiful UI**: Modern interface with animated flags and South Asian color palette
- 🛡️ **Content Filtering**: Automatically declines offensive, biased, or off-topic questions
- 💬 **Chat Interface**: Smooth conversation experience with message history
- 🌈 **Animated Background**: Floating flags and gradient effects

## 🚀 Quick Start

### Prerequisites

1. **Node.js, npm, Git** installed.
1. **Ollama** installed and running locally
2. **Llama 3.2** model downloaded

```bash
# Install Ollama (if not already installed)
# Visit: https://ollama.ai

# Pull Llama 3.2 model
ollama pull llama3.2
# Let the 2 gb download happen

# Start Ollama (it should be running on localhost:11434)
ollama serve
```

### Installation

1. Go to the project root and run the following command to install the required packages:
```bash
npm install
```

2. Start your development server:

```bash
npm run dev
# It should be running on http://localhost:5000/
```

## 🎯 What the AI Can Do

### ✅ Answers Questions About:
- SAARC organization and its history
- Member nations (culture, economy, politics)
- Regional cooperation initiatives
- South Asian diplomacy and relations
- Cultural similarities and differences
- Economic partnerships
- Historical context

### ❌ Will NOT Answer:
- Questions unrelated to SAARC or South Asia
- Offensive or inflammatory content
- Requests to take sides in conflicts
- Sensitive military/security details
- Biased political propaganda

## 🔧 Configuration

### Change AI Model
Edit line 67 in `SAARCAIAssistant.jsx`:
```jsx
model: 'llama3.2',  // Change to your preferred model
```

### Adjust System Prompt
Modify the `systemPrompt` variable (lines 42-72) to customize the AI's behavior.

### Customize Colors
The UI uses a South Asian color palette:
- Orange: `from-orange-500`
- Green: `via-green-500`
- Blue: `to-blue-500`

Edit these in the Tailwind classes throughout the component.

## 🛠️ Troubleshooting

### AI Not Responding
- Ensure Ollama is running: `ollama serve`
- Check if model is installed: `ollama list`
- Verify Ollama is accessible at `http://localhost:11434`
